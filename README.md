# Brendo Santos Tavares

Portfólio de candidatura para Desenvolvedor Front-End Júnior, construído com React, TypeScript e Vite.

## Requisitos

Node.js 20.19+ ou 22.12+ e npm.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Verificações

```sh
npm run lint
npm run build
npm run preview
```

`npm run build` executa `tsc -b` antes do bundle. Não há script `typecheck` separado.

## Deploy na Vercel

Importe o repositório com preset Vite. O comando de build é `npm run build` e o diretório de saída é `dist`.

## Conteúdo

Os projetos apresentados ficam em `src/data/projects.ts`; descrições e tecnologias são locais e não dependem de chamadas à API do GitHub. O case AVESSO X GO usa fatos do README e da estrutura pública do repositório.
